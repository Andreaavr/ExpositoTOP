# Registro de decisiones de arquitectura (ADR)

Un ADR (*Architecture Decision Record*) documenta una decisión relevante: su contexto, la
decisión tomada y sus consecuencias. Se escriben una vez y no se modifican; si una decisión
cambia, se crea un ADR nuevo que sustituye al anterior.

Formato utilizado (Michael Nygard): **Estado · Contexto · Decisión · Consecuencias**.
